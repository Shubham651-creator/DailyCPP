# Design Patterns

- Famous `Gang of four` books divides design pattern into 3 categories

## A. Creational Design pattern
>> It deals with object creation.

### This controls:
- who will create object
- when objects are created
- how objects are created
- who owns object

----
### 1. Factory Pattern
> Factory provides an interface for creating objects without exposing object creation logic.
- achieve Open-closed design principle

### 3. Build Pattern
> Construct complex object step by step.

### 4. Prototype Pattern
> Creating new object by copying existing one.
